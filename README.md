# Timezone App

하노이 · 샌디에이고 · 서울 3개 도시의 실시간 시계를 보여주는 모바일 웹앱 (PWA).

## 배경 / 의도

베트남(하노이)-한국(서울)-미국(샌디에이고)을 오가며 생활하면서 시차를 한눈에 보기 위해 만든 개인용 도구.

## 현재 상태

🟡 완성

## 기능

- 3개 도시 실시간 시계 (1초마다 갱신)
- GPS로 현재 위치 자동 감지 → 해당 도시 카드가 맨 위로
- 드래그 앤 드롭으로 카드 순서 변경
- 모바일 전용 (375–430px 화면 타겟)

## 사용 기술

- Vanilla HTML/CSS/JS (프레임워크/빌드툴 없음, `index.html` 단일 파일)
- PWA (`manifest.json`)
- Google Fonts (CDN)

## 실행 방법

`index.html`을 브라우저로 열면 바로 동작. 별도 서버/빌드 불필요.

아이콘 재생성이 필요하면:
```bash
npm install
node gen-icon.mjs
```
